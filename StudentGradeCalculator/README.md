Student Grade Calculator 🎓
Project Description

The Student Grade Calculator is a Python-based application that calculates student grades based on their marks.

It accepts a student's name and marks, validates the input, calculates the grade, and displays an encouraging message.

Objectives
Understand Python conditional statements.
Learn how to use functions.
Practice while loops.
Implement input validation.
Understand exception handling.
Technologies Used
Python 3
VS Code / IDLE

Grading Criteria
Marks	Grade

80-89	B
70-79	C
60-69	D
0-59	F
Features
Student name input.
Marks input from 0 to 100.
Automatic grade calculation.
Input validation.
Invalid input handling.
Encouraging messages for every grade.

How to Run the Project
Install Python 3.
Download or clone this repository.
Open the project folder in VS Code.
Open the terminal.
Run the following command:
bash
python grade_calculator.py
